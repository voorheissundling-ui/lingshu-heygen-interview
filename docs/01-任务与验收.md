# 任务与验收

## 目标与提供范围

在基线真实代码上完成单条数字员工视频生产纵向链，不要求全周排期重构、社媒发布或重做全站。

参考：https://www.tiktok.com/@yuchengcosmeticsfactory/video/7449962848203181354

已附assets/reference-analysis-only.mp4：33.58秒，576×1024/30fps，音视频完整解码通过。来源为本地历史缓存，哈希与历史验收记录一致；本次未重新验证在线URL身份，以附件文件和SHA256固定本题。已抽帧查看人物口播、产品、实验室、生产/品控与结尾CTA，逐句听译与精确分镜由候选人完成，不把旧自动分析当答案。

使用HeyGen公共数字人，无需复刻原人物身份、长相或声音。还原人物口播镜头的景别、构图、节奏、切换和字幕，配合工厂/产品等说明性素材，注明素材来源。保留开头口播、产品/能力说明、工厂或品控证据、结尾CTA的表达顺序；成片总长30–37秒，至少2个人物口播段和2个说明性镜头。字幕与口播对应且可读。公共数字人的动作及背景不要求逐像素复制，但须解释还原与取舍。

## 必做工作

1. 导入可编辑的脚本/分镜，至少记录镜头ID、类型（人物/说明）、起止或时长、口播文本、字幕、构图与素材来源。分析可人工完成，也可使用任意模型API或模型官网；提交分析与分镜文件。
2. 完成单任务入口及进度、错误、成片展示。启动数字员工任务后，由代码完成HeyGen提交、状态查询、下载、素材处理合成、文件保存、原内容任务/运行结果回写、播放与下载。沿原队列、原业务命令及结果验证，不另建只有外观的平行流程。
3. 将现有HeyGen client、bridge、人物/声音及运行绑定接入该任务。公共人物的实际可用性与权限须核验，不伪造自有克隆授权记录。如现有绑定仅支持另一类人物，应说明差异并做有依据的兼容改动。
4. 支持中断恢复与重复操作：已取得video_id后恢复查询，不重新生成；提交结果未知时明确提示并对账。记录原任务/run/job/请求身份及供应商video_id；持久保存任务阶段。幂等不能仅依赖前端禁用按钮。
5. 真实API错误和预算不足可读可定位；提交前核对上限，保存预算占用与已接受任务记录，并防止并发绕过。供应商账户限额与应用预算分开说明，不把“查到余额”当作已设置硬上限。

现有本地模式已完成真实FFmpeg字节生成、原队列结算与原产物登记；它没有完整原生产图的真实HeyGen证明。候选人任务是接入并修补这条链，不能把全部尚未验证事项预先称为bug。逐项现状与可改文件见验收矩阵。

## 验收场景

- 正向：无最终产物开始，导入分镜后启动原任务，实际调用HeyGen并生成完整、可解码、有口播及说明镜头的MP4；页面可播放下载，文件哈希与登记记录一致，原任务显示制作完成、待审核。
- 创作：提交带起止时间的分镜对照表，逐镜说明参考与成片的还原和取舍。以附件视频、上述表达顺序和30–37秒总长验收，不要求沿用历史自动生成的镜头切分。
- 重复：连续启动相同任务，仅保留一份有效执行与交付；原任务/run不变；不能产生无依据的第二次付费提交。
- 恢复：供应商处理中停止进程，重启后恢复查询既有video_id并完成下载和回写；提交结果未知时不自动换请求ID重提。
- 异常：用受控故障覆盖鉴权失败、限流/服务失败、下载失败、预算不足与损坏媒体。标明哪些通过真实API触发，哪些注入模拟；不得为演示故意烧钱。
- 完整性与隔离：原验证拒绝错租户、错绑定或被篡改的媒体；读取页面不触发生成；Key不出现在前端、代码、日志与提交中。
- 现场复跑：评审临时换一段口播，候选人修改输入后由代码再跑，解释请求记录、费用和恢复过程。复跑额度另行确认。

不得人工剪辑最终成片后上传冒充自动生产，也不得删除门禁或篡改数据库为succeeded。产物待人工审核不等于审核通过或已发布。
