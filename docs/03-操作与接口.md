# 操作与接口

## 命令

`pnpm run seed`：停机后初始化独立数据（会删除本包.interview-data/store并重建）。
`pnpm run render`：真实DurableContentExecutionWorker只领取session.json指定的job，通过受控本地执行端口生成视频、登记文件/产物/场景缓存；已完成job不会重做。
`pnpm run scan`：本题定向消费器调原createSocialWeeklyExecutionWorker及createSocialWeeklyProductionAdapter；claim/defer/complete为原实现，不启动全局预生产/发布恢复扫描。
`pnpm run status`：从磁盘读取周任务、content、jobs、artifact、file。
`pnpm run smoke`：重置→生成→扫描→验证→重复执行。它证明正向消费链，不覆盖所有候选人必做项。
`pnpm run dev`：127.0.0.1:4318，Ctrl+C停止。PORT可改端口。

## HTTP

GET /：验证页面。
GET /api/state：读取本题固定样例记录。
POST /api/render：定向受控生产。
POST /api/scan：定向消费回写。
GET /api/media?artifactId=原产物ID：通过原openSocialArtifactPreviewMedia读取登记媒体，限制本题租户。添加&download=1返回附件下载。

沙箱没有真实登录：身份由服务端样例固定为t，当前只有一个样例。候选人如扩展请求范围必须在服务端校验，不能接受客户端tenantId作为授权。

## 固定身份和时间

tenant=t；program=p；package=week1/version1；weekly task=video；content task=content；run=run。jobId从持久化准入生成，不按标题猜。审核状态保持review_required。

now()固定2026-10-02T12:00:00Z，保证历史周包不随面试日期过期；业务状态与日志中部分系统创建时间可能是实际时间。处理nextAttemptAt时须尊重所选时钟。请在交付说明中解释计时方案；不要把未到重试时间的任务强行标完成。

.interview-data：独立本地store、合成输入、冻结样例上下文、本地输出。.interview-data/object-storage：本题显式固定的本地对象存储；默认原项目还支持data/media/object-storage及其他存储模式。两者均不得提交。重启保留数据；seed/smoke会重置。

初次安装及FFmpeg下载需要网络；运行命令不需要外部API。bootstrap防误调用，但不是对恶意修改代码的OS隔离工具。只在本地使用，不部署此验证服务。

## 显式真实模式

离线页面仍用pnpm run dev：它经过bootstrap，清理密钥并阻断全部非本机网络。真实模式使用独立入口pnpm run real:dev，不经过bootstrap：

- 只从进程环境HEYGEN_KEY_FILE读取包外的纯Key文本文件；文件必须在仓库外、只含一行Key。服务端只注入HEYGEN_API_KEY，记录其SHA-256，不打印Key或Key文件路径。
- 启动时清理继承的其他敏感环境变量；外网只放行https://api.heygen.com/v3/和明确注册过的供应商HTTPS下载主机，localhost仅供页面和本地存储。
- 不自动打开SOCIAL_CONTENT_HEYGEN_ENABLED或HEYGEN_GENERATION_ENABLED；真实生成还必须有正数业务预算和人工审批。GET /api/real/status只返回模式、是否配置Key、凭据哈希、开关状态，不返回密钥。
- 公共人物走公开目录证据（publicCatalogRef、providerTermsRef、verifiedAt、accountId），不伪造克隆授权或同意书；克隆人物仍走原authorizationRef/consentRef校验。

当前机器上的在线部分被两个前置条件阻塞，尚未得到真实结果：D:/secrets/heygen.key不存在，且本机到api.heygen.com/help.heygen.com的连接超时（详见evidence/step2-network.txt）。这不代表真实模式代码未通过；本地启动、脱敏、白名单和公开人物校验已做单测与本地启动验证。

## 真实供应商预检

真实只读预检使用独立命令pnpm run provider:preflight，通过进程环境HEYGEN_KEY_FILE指定包外的纯Key文本文件。不要使用bootstrap运行此命令，否则密钥会被清理。该命令只做官方GET，不生成视频，不设置账户消费上限，也不证明完整制作链。它会分页读取公共人物/声音目录，核对assets/storyboard.json的人物ID、状态、引擎和语言，并检查钱包币种、余额、自动充值状态；任一条件不满足会写报告并以非零退出。正式真实模式是候选人接入任务的一部分，须保留原预算及身份核验。

## 独立真实探针

pnpm run provider:pricing：使用基线原解析器读取官方价格及ECB汇率，不生成视频。

pnpm run provider:probe --submit-approved-probe：首次生成需显式设置HEYGEN_KEY_FILE（包外纯Key文件）与HEYGEN_INTERVIEW_MAX_CNY（获授权额度，最多30）。只允许固定短片的一次提交，持久化身份；之后pnpm run provider:probe只查询同一video_id并下载。首次提交计费，不自动重提；结果未知时先对账，不删除state重做。进程强杀可能留下execution.lock，确认无运行进程后可清理锁，必须保留state。这只是环境探针，不是完整业务预算和恢复实现。
