# 操作与接口

## 命令

`pnpm run seed`：停机后初始化独立数据（会删除本包.interview-data/store并重建）。
`pnpm run render`：真实DurableContentExecutionWorker只领取session.json指定的job，通过受控本地执行端口生成视频、登记文件/产物/场景缓存；已完成job不会重做。
`pnpm run scan`：本题定向消费器调原createSocialWeeklyExecutionWorker及createSocialWeeklyProductionAdapter；claim/defer/complete为原实现，不启动全局预生产/发布恢复扫描。
`pnpm run status`：从磁盘读取周任务、content、jobs、artifact、file。
`pnpm run smoke`：重置→生成→扫描→验证→重复执行。它证明正向消费链，不覆盖所有候选人必做项。
`pnpm run dev`：127.0.0.1:4318，Ctrl+C停止。PORT可改端口。

## HTTP

GET /：任务工作台页面。
GET /api/state：读取本题固定样例记录（只读）。
GET /api/pipeline：读取 Step 5 阶段、任务身份、费用、回写结果和下载地址（只读，不触发执行）。
POST /api/start：唯一启动入口；服务端持久幂等键 + 文件租约，重复启动返回同一完成产物或 already_running。
POST /api/scan：定向重新结算周任务；不提交、不渲染、不重复回写。
GET /api/media?artifactId=原产物ID：通过原openSocialArtifactPreviewMedia读取登记媒体，限制本题租户。添加&download=1返回附件下载。

沙箱没有真实登录：身份由服务端样例固定为t，当前只有一个样例。候选人如扩展请求范围必须在服务端校验，不能接受客户端tenantId作为授权。

## 固定身份和时间

tenant=t；program=p；package=week1/version1；weekly task=video；content task=content；run=run。jobId从持久化准入生成，不按标题猜。审核状态保持review_required。

now()固定2026-10-02T12:00:00Z，保证历史周包不随面试日期过期；业务状态与日志中部分系统创建时间可能是实际时间。处理nextAttemptAt时须尊重所选时钟。请在交付说明中解释计时方案；不要把未到重试时间的任务强行标完成。

.interview-data：独立本地store、合成输入、冻结样例上下文、本地输出。.interview-data/object-storage：本题显式固定的本地对象存储；默认原项目还支持data/media/object-storage及其他存储模式。两者均不得提交。重启保留数据；seed/smoke会重置。

初次安装及FFmpeg下载需要网络；运行命令不需要外部API。bootstrap防误调用，但不是对恶意修改代码的OS隔离工具。只在本地使用，不部署此验证服务。

## 显式真实模式

离线页面仍用pnpm run dev：它经过bootstrap，清理密钥并阻断全部非本机网络。真实模式使用独立入口pnpm run real:dev，不经过bootstrap：

- 只从进程环境HEYGEN_KEY_FILE读取包外的纯Key文本文件；文件必须在仓库外、只含一行Key。服务端只注入HEYGEN_API_KEY，记录其SHA-256，不打印Key或Key文件路径。
- 启动时清理继承的其他敏感环境变量；外网只放行https://api.heygen.com/v3/和明确注册过的供应商HTTPS下载主机，localhost仅供页面和本地存储。
- 不自动打开SOCIAL_CONTENT_HEYGEN_ENABLED或HEYGEN_GENERATION_ENABLED；真实生成还必须有正数业务预算和人工审批。GET /api/real/status只返回模式、是否配置Key、凭据哈希、开关状态，不返回密钥。
- 公共人物走公开目录证据（publicCatalogRef、providerTermsRef、verifiedAt、accountId），不伪造克隆授权或同意书；克隆人物仍走原authorizationRef/consentRef校验。
- 代理变量不属于敏感变量，会被保留；本机直连HeyGen超时，但系统代理127.0.0.1:7897可用。运行真实模式前须设置HTTPS_PROXY/HTTP_PROXY和NODE_USE_ENV_PROXY=1，且不得关闭TLS校验。

在线只读预检已完成：包外Key文件（本机实际为D:/secrets/heygen.key.txt，Windows隐藏扩展名）可用，钱包为wallet/USD、余额2.3、自动充值关闭；分镜avatar/voice均找到并通过条件。直连api.heygen.com/help.heygen.com的TCP 443超时，经系统代理可达；真实模式守卫经代理访问API返回401，非白名单域名被拦截，详见evidence/step2-preflight.txt、step2-preflight-summary.json、step2-network.txt、step2-proxy-network.txt和step2-live-check.json。公共目录在20页安全上限处截断（每种1000条），目标ID已在前1000条中找到并验证，报告保留catalog_truncated_after_20_pages警告；本地启动、脱敏、白名单和公开人物校验已做单测与本地启动验证。

## 真实供应商预检

真实只读预检使用独立命令pnpm run provider:preflight，通过进程环境HEYGEN_KEY_FILE指定包外的纯Key文本文件。不要使用bootstrap运行此命令，否则密钥会被清理。本机直连HeyGen不可用，运行前需设置HTTPS_PROXY/HTTP_PROXY和NODE_USE_ENV_PROXY=1（系统代理127.0.0.1:7897），不要关闭TLS校验。该命令只做官方GET，不生成视频，不设置账户消费上限，也不证明完整制作链。它会分页读取公共人物/声音目录，核对assets/storyboard.json的人物ID、状态、引擎和语言，并检查钱包币种、余额、自动充值状态；声音语言支持English→en等名称归一化。20页后仍有下一页时报告catalog_truncated_after_20_pages，此时只把已找到并通过条件的目标ID作为正面证据，不宣称目录完整。任一关键条件不满足会写报告并以非零退出。本机实际执行已返回READ_ONLY_COMPLETE：wallet/USD、余额2.3、自动充值关闭，分镜avatar/voice均通过；未生成、未计费。正式真实模式是候选人接入任务的一部分，须保留原预算及身份核验。

## 独立真实探针

pnpm run provider:pricing：使用基线原解析器读取官方价格及ECB汇率，不生成视频。本机需经系统代理；2026-10-23读取到Photo Avatar 2.31 USD/min、ECB日期2026-10-22、1 USD=6.674341811691209 CNY，约15.42 CNY/min。该数值只覆盖Photo Avatar费率，不含声音/其他费用。

pnpm run provider:probe --submit-approved-probe：首次生成需显式设置HEYGEN_KEY_FILE（包外纯Key文件）与HEYGEN_INTERVIEW_MAX_CNY（获授权额度，最多30）。只允许固定短片的一次提交，持久化身份；之后pnpm run provider:probe只查询同一video_id并下载。首次提交计费，不自动重提；结果未知时先对账，不删除state重做。进程强杀可能留下execution.lock，确认无运行进程后可清理锁，必须保留state。这只是环境探针，不是完整业务预算和恢复实现。

## Step 3 单镜头真实闭环

pnpm run step3:single-shot 是独立于业务链路的单镜头付费脚本，对应Step 3“提交→查询→下载→校验”验证：

- 读取包外HEYGEN_KEY_FILE，拒绝仓库内Key；只打印凭据哈希和脱敏账号引用，不打印Key。
- 以公共人物证据（ownership=public、publicCatalogRef、providerTermsRef、verifiedAt、不透明accountId）建立运行时绑定；不生成authorizationRef/consentRef。克隆路径保持不变。
- 默认镜头为storyboard的hook（0–5秒），要求口播时长3–8秒；提交前校验预检证据、公共avatar/voice、钱包USD/非负/自动充值关闭。
- 必须先设置HEYGEN_INTERVIEW_MAX_CNY（本次10，范围(0,30]）；提交前按官方2.31 USD/min与ECB汇率预估“口播秒数+3秒”费用，超过预算或超过钱包可覆盖额度即失败关闭。
- `--prepare-only`只创建状态、不发POST；真实提交必须再加`--submit-approved-shot`。单次POST带Idempotency-Key，持久化requestId/requestHash/预算/钱包快照/公开证据；提交后按同一videoId轮询，不自动重提。未知状态会保留submission_unknown并拒绝再次提交。
- 下载只接受HTTPS的*.heygen.ai/*.heygen.com，限制110MB；不把签名URL写入证据。随后用FFmpeg校验时长、宽高、编码、音轨和全片解码，并抽3帧。
- 状态与临时文件在`.interview-data/step3-single-shot/`（不提交）；脱敏结果在`evidence/step3-single-shot.json`，媒体在`evidence/step3-single-shot.mp4`。
- 本机已完成一次真实提交：video_id `15011b5480450b621a5c2248bb74cae5`，时长3.21306秒，720×1280/H.264/AAC，322958字节，SHA-256 `ebe21080c420b1d75040140c35ceab45336ea7652afba68fcb9b2e4d0968f5eb`；钱包2.30→2.15 USD，观察扣费0.15 USD（约1.0012 CNY），预算10 CNY内。`paidSubmissions=1`，不要为“再确认”重复运行。
- 边界：该脚本不写业务任务、不生成artifact、不设置review_required，也不等于完整数字员工链路；人工听感/ASR验收仍待完成。

## Step 4 多镜头真实合成

Step 4 仍使用包外 `HEYGEN_KEY_FILE`、系统代理、`NODE_USE_ENV_PROXY=1`，不关闭 TLS 校验。所有付费动作共用 `HEYGEN_INTERVIEW_MAX_CNY` 总额上限（本次 8 CNY），并写入共享账本 `.interview-data/step4-shots/budget.json`（不提交）。

1. 人物镜头：`pnpm run step4:shot -- --shot=<hook|capabilities|cta> --prepare-only`，确认 `paidSubmissions=0` 后再加 `--submit-approved-shot`。每个镜头独立状态目录 `.interview-data/step4-shots/<shotId>/`，重启只按已保存的 `videoId` 查询，不重提。请求显式带 `fit=cover`，修复 Step 3 的上下白边；下载后用 FFmpeg 检查 9:16、编码、全片解码，并做边缘条带检测（near-black/near-white 连续行/列），同时抽 3 帧。
2. 说明镜头旁白：`pnpm run step4:narration -- --shot=<product-range|lab-process|factory-quality> --prepare-only`，确认后再加 `--submit-approved-shot`。使用与人物相同公共声音，经 `POST /v3/voices/speech` 生成音频；引擎从预检的 `available_engines` 选择（本机为 `orca`），不伪造克隆声音。音频落到 `.interview-data/step4-narration/<shotId>/narration.mp3`，记录引擎、时长、SHA-256 和钱包扣费。
3. 合成：`pnpm run step4:compose` 只生成计划/清单/时间轴音轨；加 `--render` 才调用 `desktop/render.cjs` 渲染 1080×1920。时间轴按实测镜头时长回填，人物口播不裁剪、不变速；说明镜头至少比旁白长 0.15 秒。字幕由清单 cues 烧录，不使用手工剪辑。
4. 本机结果：3 段人物口播（hook 3.21306 s、capabilities 4.70204 s、cta 7.15755 s）+ 3 段说明旁白（5.93 / 5.25 / 5.88 s），成片 33.52 s、1080×1920、H.264/AAC、8,995,181 字节，SHA-256 `c8fe2f84b25444e048b858dd5274ceb3942f4bd620d6147ee9b7dde03ecf815f`。6 次付费操作合计记账 5.339473 CNY（上限 8），钱包 2.15→1.35 USD。
5. 证据：`evidence/step4-final.mp4`、`evidence/step4-final.json`、`evidence/step4-manifest.json`、`evidence/step4-frames/*.png`，以及每镜头 `evidence/step4-<shot>.json` 和旁白 JSON/MP3。原始状态、清单与时间轴音轨在 `.interview-data/step4-*`，不提交。
6. 边界：这是隔离的多镜头合成，不改业务数据库、不写 `review_required`；完整业务 bridge、任务回写、页面播放下载仍属于 Step 5。

## Step 5 原任务回写 + 页面工作台

启动：`pnpm run dev`，打开 `http://127.0.0.1:4318/`。页面只通过“启动任务”执行；刷新、读取 `/api/pipeline`、播放和下载均不会生成或重新提交。服务仍经 bootstrap 启动，不访问外网；Step 5 复用 Step 4 已付费并落盘的供应商记录，不产生新的 HeyGen 调用。

1. 启动前固定身份：从 `.interview-data/session.json` 读取 task=video、content task=content、run=run、jobId，从 `assets/storyboard.json` 读取分镜 SHA-256、公共 avatar/voice；幂等键为 `SHA-256(taskId|runId|storyboardSha256|avatarId|voiceId)`。分镜或人物变化时拒绝沿用旧状态。
2. 阶段固定为：`prepared` → `submitting` → `accepted` → `generating` → `downloading` → `compositing` → `writing_back` → `review_required`，每阶段持久化起止时间、中文说明和证据来源。
3. 供应商阶段优先读取 `.interview-data/step4-shots/<shot>/state.json`、`.interview-data/step4-narration/<shot>/state.json`；干净目录退回到已提交的 `evidence/step4-<shot>.json`。要求 3 段人物镜头 + 3 段旁白，校验分镜 SHA、已存媒体 SHA、付费与预算记录；页面注明“Step 5 不重复提交、不再扣费”。
4. 合成：本地 Step 4 清单和输入存在时，复用 `desktop/render.cjs` 重新自动合成（`composition.mode=recomposed`）；否则校验并复用 `evidence/step4-final.mp4` 的 SHA（`reused-verified-evidence`）。成片必须 30–37 秒、1080×1920、H.264/AAC、可完整解码。干净目录路径已用 `pnpm run seed` 实测：无 `.interview-data/step4-*` 时成功复用提交证据，预算上限/付费次数也回退读取 `evidence/step4-final.json`，见 `evidence/step5-clean-seed.json`。
5. 回写在 `local()` 受控执行端口内调用原命令：`storeSocialContentFile` → `registerSocialContentFile` → `createSocialContentArtifact`（`trustedAgentOrigin=true`、`requireHumanReview=true`、`kind=short_video`）。产物固定 `review_required`，`technicalReview.approved=false`、`creativeReview.approved=false`；状态不伪造为 succeeded。
6. 同步写每场景 G4 receipt（`status=review_required`，format/duration/audio_visual_sync/caption/linked_assets/render 通过，sensitive_data 留待人工），以及 scene cache。最终 MP4 作为 voice 与各场景 asset 的唯一源，`initialSceneSourceHashes`、`initialSceneCacheInput.manifestHash`、`renderInput.manifest/sourceManifest` 和空 `mediaRemap` 均与原场景回写不变量一致。
7. 结算：领取固定周任务 `video`，调用原 `createSocialWeeklyProductionAdapter` 与 `createSocialWeeklyExecutionWorker`；成功后 `complete`。成功后 content 行为 `asset_review`、run 为 `succeeded`、weekly 为 `succeeded`，但 artifact 仍是 `review_required`，等待人工审核。
8. 哈希链：`file.content_sha256` = artifact `content.mediaStorage.video.sha256` = 合成成片 SHA-256 = `/api/media?...&download=1` 实际下载字节 SHA-256。本次均为 `c8fe2f84b25444e048b858dd5274ceb3942f4bd620d6147ee9b7dde03ecf815f`（8,995,181 字节）。
9. 持久幂等与租约：删除页面 `busy` 布尔值；启动前检查已完成产物和 `.interview-data/step5/state.json`，用 `fs.open(execution.lock,'wx')` 原子抢占 60 秒租约，记录 owner/pid/expiresAt，运行中按阶段心跳并检查 PID 存活；过期租约可清理。重复启动返回 `already_complete` 或 `already_running`，不新增 job/file/artifact。
10. 页面展示：内容任务、周任务、run、jobId、短幂等键、分镜 SHA、avatar/voice、供应商阶段与每镜头 `requestId`/`video_id`、预算/已记账/付费次数、成片 SHA、artifact/file ID、`review_required` 与两项审核未通过、周任务结算；提供视频播放器和 `下载 MP4`。页面不读取、展示或回传 Key。
11. 错误统一转为中文可读文案（seed 缺失、分镜无效、执行中、供应商证据缺失、哈希不一致、成片校验失败、合成失败、任务终止、产物非 review_required、周任务结算失败、租约丢失）；鉴权/限流/预算/下载/媒体损坏有兜底分类，URL 会先脱敏。
12. 本机结果：jobId `b723a160da693f0`；artifact `socialart_972a87313212207c9f9dc88c`（`review_required`）；file `socialfile_0dad21934ca019a3d720deb6`；成片 33.52 秒；Step 4 记账 5.339473 CNY（8 CNY 上限，6 次付费，Step 5 无新增）；重复 `POST /api/start` 返回 `already_complete`，jobs/artifacts/files 仍各 1 条。证据：`evidence/step5-writeback.json`、`evidence/step5-page.png`、`evidence/step5-page-bottom.png`。
13. 边界：页面启动的是离线业务回写，不是重新调用 HeyGen 的完整在线生成；真实供应商阶段来自 Step 4。人工听感/ASR 和人工审核仍未完成，是 Step 6–8 的后续工作。
