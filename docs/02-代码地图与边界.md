# 代码地图

建议阅读顺序：README→interview/control.ts→主适配器→周worker→持久队列→结果核验。另读docs/04-模块现状与验收矩阵.md中HeyGen纵向链；不必通读整个依赖目录。

| 文件 | 职责 / 是否建议修改 |
|---|---|
| server/runtime/socialWeeklyProductionAdapter.ts | 主考核模块，533行原源码；核验冻结范围、读取/恢复内容、检查真实产物。允许有证据的局部重构 |
| server/runtime/socialWeeklyExecutionWorker.ts | 原周任务领取、租约、延后、失败、完成。完成前再次验证结果 |
| server/runtime/weeklyContentProductionIdentity.ts | 周包/发布任务/共享原创/内容任务绑定 |
| server/runtime/socialWeeklyResultValidation.ts | 原结果、媒体字节、版本及身份核验；不允许为过测试削弱 |
| server/starter198/socialContentOriginalRunQueueRecovery.ts | 既有run队列恢复，需完整原执行证据 |
| server/contentExecution/durableQueue*.ts、context.ts | 原持久队列、租约、重试、结算与执行上下文 |
| server/storage/pbStore.ts、dataAuthority.ts | 原本地JSON持久化和原子文件锁；本题显式local域，不连接真实PocketBase |
| server/starter198/socialContentFiles.ts、socialContentOutputs.ts、socialContentSceneReworkService.ts | 原文件、产物与场景缓存命令；实际媒体证据从这里核验 |
| desktop/render.cjs及相邻依赖 | 原本地合成器；源片段拼接加合成音频，非真实数字人口播 |
| interview/bootstrap.mjs | 子进程沙箱配置，清除继承密钥、固定独立数据目录、防误调用外部网络；不是操作系统安全沙箱 |
| interview/control.ts | 面试装配与本地执行端口；有职责注释。seed使用基线自带fixture生成合成上游数据，然后丢弃预置最终产物/审核结果；运行时重新合成并用原命令登记。它不调用完整LangGraph域生产执行器 |
| interview/web.ts、public/index.html | 本地HTTP和精简验证界面，候选人应完善操作与反馈 |
| interview/smoke.ts | 正向和重复执行检查；会重置本题数据 |
| server/runtime/*.test.ts（两组指定测试）、server/contentExecution/durableQueue.test.ts | 原基线回归，不要求读取其他全部测试 |

核心改动建议限制在interview适配/界面及有充分依据的原模块。复杂依赖仅为保持原代码导入完整，不要求候选人改客服、广告、采集等无关功能。原模块状态语义、原审核/发布门禁、资料与租户边界保持成立。

若新增依赖须说明原因并更新lock。不可上传整个本包到public仓库，也不应把来源源码用作其他用途。本题没有附原Git历史或生产配置。

## 本轮新增重点

真实HeyGen接入重点：server/lib/heygen.ts、heygenPresenters.ts、studioBoundHeyGenVoice.ts；server/integrations/heygen.ts；server/starter198/socialContentHeyGenBridge.ts、socialContentWholeTrackHeyGenBridge.ts、socialContentHeyGenRuntimeBinding.ts及相关预算模块。它们已随依赖附带，当前没有真实API通过证明。允许为公共人物和分镜输入做有依据的兼容改动，不绕过原身份及费用边界。任务入口和分镜导入可在interview目录实现，结果必须回到原任务记录。
